# Phase 03 — Decision Service Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Decision service consumes `invoice-submitted`, runs Gate 1 (duplicate fingerprint) → Gate 2 (deterministic validators) → the agent (swappable port; stub + OpenRouter adapters) → Gate 3 (the pure router enforcing the D-012 posture), publishes `decision-made`, exposes runtime-tunable thresholds (M13), and is **provably incapable** of auto-approving above the ceiling even with a malicious agent (M12) — demonstrated by an adversarial suite over all 20 shipped fixtures and a two-service compose smoke.

**Architecture:** Spec §4 + decisions D-003 (port/adapters), D-011 (dup = router gate #1), D-012 (posture: $250 base · category caps · $400 trusted-vendor uplift), D-015 (own keys only: `fp:*`, `trust:*`, `config:*`, `processed:*`). The agent only recommends; the router decides. Correction to D-012's example (logged in Task 9): the uplift demo fixture must be a **travel** vendor (no category cap) — a SaaS example would stay capped at $200 regardless of trust.

**Tech Stack:** Python 3.12 · FastAPI · pydantic v2 · afcommon · httpx (OpenRouter, OpenAI-compatible JSON mode) · Dapr pub/sub + state + **secrets** · Redis.

## Global Constraints

- Money in integer cents; FX conversion via `Decimal` with `ROUND_HALF_UP`, once, in Gate 2.
- The router is a **pure function**; nothing the agent returns can widen an outcome past a guard. Reject-severity rules: `MEAL-03` only.
- Fail loud (M15): LLM transport failure → retries (3, exponential backoff) → route `human_review` with violation `AGENT-UNAVAILABLE` — never silent, never blind approval.
- Idempotency (M10): dedupe every consumed event id (same `processed:*` guard pattern as intake; use a CAS transform for any read-modify-write).
- No noqa comments (B008 handled globally in pyproject). JSON logs with correlation/invoice ids on every handler path that logs (M14).
- Branch `feature/decision` off `main`; conventional commits; controller pushes per task; PR at the end (D3). Baseline: **75 passed**.
- Default thresholds (cents): global ceiling **25000**, trusted uplift ceiling **40000**, confidence **0.80**, SaaS monthly cap **20000**, meals per-attendee **7500**. All runtime-tunable via `PUT /api/config/thresholds`.
- Test fixtures: load `sample-invoices.json` from the repo root (`pathlib.Path(__file__).resolve()` walk-up); `expected.route` is the graded truth, `expected.violations` informational.

```python
import json
from pathlib import Path

from pydantic import BaseModel

from afcommon.state import StateStore, cas_update

_THRESHOLDS_KEY = "config:thresholds"
_FX_KEY = "config:fx-rates"


class Thresholds(BaseModel):
    ceiling_cents: int = 25000
    trusted_ceiling_cents: int = 40000
    min_confidence: float = 0.80
    saas_monthly_cap_cents: int = 20000
    meals_per_attendee_cents: int = 7500


def _find_repo_file(name: str) -> Path:
    here = Path(__file__).resolve()
    for parent in here.parents:
        if (parent / name).exists():
            return parent / name
    raise FileNotFoundError(name)


class ConfigRepo:
    def __init__(self, store: StateStore):
        self._store = store

    async def get_thresholds(self) -> Thresholds:
        value, _ = await self._store.get(_THRESHOLDS_KEY)
        if value is None:
            defaults = Thresholds()
            await cas_update(self._store, _THRESHOLDS_KEY, lambda _: defaults.model_dump())
            return defaults
        return Thresholds.model_validate(value)

    async def update_thresholds(self, partial: dict) -> Thresholds:
        unknown = set(partial) - set(Thresholds.model_fields)
        if unknown:
            raise ValueError(f"unknown threshold keys: {sorted(unknown)}")

        def merge(current: dict | None) -> dict:
            base = Thresholds.model_validate(current) if current else Thresholds()
            return Thresholds.model_validate({**base.model_dump(), **partial}).model_dump()

        merged = await cas_update(self._store, _THRESHOLDS_KEY, merge)
        return Thresholds.model_validate(merged)

    async def get_fx_rates(self) -> dict[str, float]:
        value, _ = await self._store.get(_FX_KEY)
        if value is None:
            seed = json.loads(_find_repo_file("sample-invoices.json").read_text())["fxRates"]
            await cas_update(self._store, _FX_KEY, lambda _: seed)
            return seed
        return value
```

### Task 2: Gate 2 — deterministic validators

**Files:**
- Create: `services/decision/src/validators.py`
- Test: `services/decision/tests/test_validators.py`

**Interfaces:**
- Consumes: `Thresholds`; invoice dicts in fixture shape (as delivered inside `InvoiceSubmittedPayload.invoice`).
- Produces: `ValidationResult` (pydantic): `usd_cents: int`, `hard_stops: list[str]` (rule ids), `notes: list[str]` (human-readable, feed the router's synthesized reasoning) · `validate(invoice: dict, fx_rates: dict, thresholds: Thresholds) -> ValidationResult`. Pure; never raises on content (malformed math is a *finding*, not an exception).

Rules (exact):
- **FX:** if `currency != "USD"`: `usd_cents = round_half_up(total * rate)`; missing rate → hard stop `GLOBAL-FX`; converted `usd_cents > 100000` **or** `> thresholds.ceiling_cents` → hard stop `GLOBAL-FX`.
- **GLOBAL-MATH:** `sum(round_half_up(quantity*unitPrice)) + tax_cents != total_cents` (all cents math) → hard stop.
- **GLOBAL-RECEIPT:** `usd_cents > 2500` and not `receiptPresent` → hard stop.
- **GLOBAL-VENDOR:** `vendorKnown` falsy → hard stop.
- **MEAL-01 (missing info):** category `meals` and `attendees` absent/None → hard stop `MEAL-01`.
- **TRAVEL-02:** category `travel` and `usd_cents > 150000` → hard stop.

### Task 6: Gate 3 — the router + the M12 adversarial suite

**Files:**
- Create: `services/decision/src/router.py`
- Test: `services/decision/tests/test_router.py`, `services/decision/tests/test_m12_adversarial.py`

**Interfaces:**
- Produces: `RouterDecision` (pydantic): `route: Route`, `violations: list[str]`, `reasoning: str`, `effective_ceiling_cents: int` · `route_invoice(*, duplicate: bool, validation: ValidationResult, agent: AgentRecommendation | None, thresholds: Thresholds, trusted: bool, invoice: dict) -> RouterDecision` — **pure function**.

**Decision order (exact; first match wins):**
1. `duplicate` → route `duplicate`, violations `["GLOBAL-DUP"]`, synthesized reasoning ("Already processed — a submission is never paid twice.").
2. `agent is None` → `human_review`, violations `["AGENT-UNAVAILABLE"] + validation.hard_stops`, synthesized reasoning.
3. `"MEAL-03" in agent.policy_violations` → `reject` (the only reject-severity rule).
4. `validation.hard_stops` non-empty **or** `agent.fraud_signals` non-empty → `human_review`, violations = hard_stops + fraud signals (+ agent violations).
5. Ceiling: `base = thresholds.trusted_ceiling_cents if trusted else thresholds.ceiling_cents`; category cap: saas → `thresholds.saas_monthly_cap_cents`; meals → `attendees * meals_per_attendee_cents` (attendees guaranteed by Gate 2); `effective = min(base, cap)` (no cap for other categories). `validation.usd_cents > effective` → `human_review` + `AUTONOMY-CEILING`.
6. `agent.confidence < thresholds.min_confidence` → `human_review` + `AUTONOMY-CONFIDENCE`.
7. `agent.policy_violations` non-empty → `human_review` (violations pass through).
8. else `auto_approve`, reasoning = agent.reasoning.

Reasoning: routes 1–2 synthesized templates; 3–8 agent reasoning (+ appended stop notes from `validation.notes`).
