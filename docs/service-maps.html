Decision

the brain — AI recommends, deterministic router decides
Python 3.12FastAPIOpenRouter LLM DecisionAgent port — swappable: handrolled / stub policy.md rulesDapr: pub/sub · state · secrets

IN · events + config

subscribes invoice-submitted — every new invoice
subscribes payment-completed — to record which vendors earned trust
PUT /api/config/thresholds — controller tunes ceiling/confidence at runtime, no redeploy

INSIDE

1Gate 1 — duplicate? fingerprint (vendor + invoice № + total), atomic first-write. A duplicate stops here: the LLM is never called
2Gate 2 — hard facts, no AI: currency → USD, line-item math, receipt, known vendor, required info, travel > $1,500
3Ask the agent (the only LLM step): relevant policy rules in → recommendation, confidence, violations, plain-language reasoning out. Provider down? Escalate to a human — never guess
4Gate 3 — the router (~40 lines of pure code) combines it all. The agent can lower an outcome, never raise it

OUT

publishes decision-made — one event whatever the route, carrying the route, the agent's rationale, the amount, and the ceiling used
owns: dedupe fingerprints · thresholds config · vendor trust historyF6 M12 M13 M15

Approval

human-in-the-loop — a pause that survives anything
Python 3.12FastAPIafcommon Dapr: pub/sub · stateno timers · no workers · no memory queues

IN · events + approver actions

subscribes decision-made — only human_review routes
GET /api/approvals/queue — escalated items with the agent's recommendation, confidence, cited rules
POST /api/approvals/{id}/verdict — approve / reject / send back, one action

INSIDE

1The pause is a record: escalation written to the state store — nothing waits in memory, so a restart can't lose it
2Queue index updated atomically, so concurrent escalations never drop an entry
3Verdict applies exactly once: compare-and-swap on “still pending” — double-clicks and retries have one effect
4Records who decided and when — the audit trail's “final call” answer

OUT

publishes approval-resolved — approved / rejected / needs-info; the flow resumes exactly where it paused
owns: escalation records · pending queue indexF4 F5 M11

Payment

the money — a saga where every step has an undo
Python 3.12FastAPIinteger cents — no floats PaymentSaga (persisted step-marker)mock PaymentProviderDapr: pub/sub · state

IN · events

subscribes decision-made — auto_approve routes
subscribes approval-resolved — human-approved items

INSIDE

0Guards first: already processed? skip (idempotent). Auto-approved? independently re-check amount ≤ ceiling — a second service must also be wrong for money to move
1Reserve budget by atomic compare-and-swap — two concurrent approvals can never overspend a department budget
2Execute payment (mock provider; test fixtures can force a failure — only when the injection flag is on)
3On failure — compensate: release the reservation, mark it, tell everyone. No orphaned money, ever
4Crash-safe: the saga's progress is a stored record; after a restart it resumes or rolls back from exactly where it stopped

OUT

publishes payment-completed — amount + remaining budget
publishes payment-failed — with compensated: true
owns: department budgets · reservations · saga recordsF3 M9 M10 M12

Audit

the memory — an immutable trail nobody can edit
Python 3.12FastAPIappend-only trail Dapr: pub/sub · state · service invocation (server)

IN · everything

subscribes all five events — every step of every invoice
GET /trail/{correlationId} — called by Intake via Dapr service invocation (the system's one sync service-to-service call)

INSIDE

1Append, never overwrite: each event lands as a timestamped entry under its correlation id
2One id tells the whole story: extracted data → rules applied → the agent's reasoning → who made the final call → what was paid
3Proves the ceiling held: every auto-approval stores the amount and the ceiling in force at decision time — the auditor checks evidence, not trust

OUT

The complete decision trail for any invoice, ready for an auditor or the UI's timeline view
owns: the audit trail (append-only)F9 F10 M14
